# API Documentation

Full interactive OpenAPI docs are auto-generated by FastAPI at
`http://localhost:8000/docs` (central platform) and
`http://localhost:800{1,2,3,4}/docs` (each backend service) once running.
This file is a static summary for quick reference.

## Central Platform (`:8000`)

| Method | Path | Description |
|---|---|---|
| GET | `/health` | Platform health check |
| GET | `/services` | List monitored services |
| GET | `/services/{id}/metrics` | Recent metric samples for a service |
| POST | `/services/{id}/poll-now` | Manually poll + run detection immediately |
| GET | `/incidents` | List incidents (optional `?status=` filter) |
| GET | `/incidents/{id}` | Incident detail |
| POST | `/incidents/{id}/acknowledge` | Acknowledge (400 if already acknowledged) |
| POST | `/incidents/{id}/resolve` | Resolve (400 if already resolved) |
| POST | `/incidents/{id}/rca` | Run rule engine + LLM explanation, store as Recommendation |
| POST | `/incidents/recommendations/{id}/verify` | Human verifies/rejects/modifies an RCA recommendation |
| GET | `/sla/rules` | List SLA policy by severity |
| GET | `/sla/summary` | Aggregate compliance stats |
| POST | `/conversion/legacy-incidents` | Upload + convert a legacy CSV (multipart file) |

## Backend services (auth :8001, orders :8002, payments :8003, db-proxy :8004)

Each exposes:
- `GET /health`
- `GET /metrics` (Prometheus exposition format)
- `POST /admin/inject-latency?ms=N` — requires `X-Admin-Token` header (see below)
- `POST /admin/inject-errors?rate=0.0-1.0` — requires `X-Admin-Token` header
- `POST /admin/simulate-down?down=true` — requires `X-Admin-Token` header
- `POST /admin/reset` — requires `X-Admin-Token` header

**Admin authentication:** every `/admin/*` endpoint requires an
`X-Admin-Token` header matching that service's `FAULT_INJECTION_TOKEN`
env var (default `dev-admin-token-change-me` locally, see
`.env.example`). Added during the security audit - these endpoints can
force a monitored service into a down/error state, so they must not be
callable by anyone who can merely reach the port. A missing or wrong
token returns `401`.

Plus service-specific business endpoints:
- **auth-service:** `POST /login`, `GET /users`
- **orders-service:** `POST /orders`, `GET /orders`, `GET /orders/{id}`
- **payments-service:** `POST /payments`, `GET /payments/{id}`,
  `POST /admin/simulate-db-timeout?on=true` (also requires `X-Admin-Token`)
- **db-proxy-service:** `POST /records` (JSON body: `{"payload": "..."}` -
  changed during the audit from an unvalidated raw query parameter to a
  proper Pydantic request body), `GET /records`,
  `POST /admin/simulate-connection-exhaustion?on=true` (also requires
  `X-Admin-Token`)

See `tests/postman_collection.json` for runnable examples of every
endpoint above, including negative cases.
